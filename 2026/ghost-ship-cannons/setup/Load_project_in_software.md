# Load project in Schneider Software

After you download the Schneider software **EcoStruxure Machine Expert Basic** (link below – you need to create an account to download it), you can either double-click on the project file `.smbp` to open it directly in the software, or open the software, click on **Open Project**, select the project file, and it will load with all the configurations such as the PLC IP address, rungs, and variables. In our case, we used the PLC M221 (TM221CE16T).
